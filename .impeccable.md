## Design Context

### Users
Players learning algorithmic thinking through narrative gameplay. They're sitting at a desk on a desktop browser, expecting a focused, story-led RPG experience. Most are curious learners (students, devs, hobbyists) — not gamers chasing reflex skill, but readers who want to *understand* what's in front of them. They will read NPC dialogue carefully and expect the UI to support that reading without distraction.

### Brand Personality
**three words:** mythic, focused, literate.

Voice: a cracked-open spellbook — wry, precise, never cute. The interface should feel like a tool a wizard-engineer left lying open on a workbench; not a flashy dashboard, not a children's app. Emotionally: confident, calm, slightly arcane.

### Aesthetic Direction
**Visual tone:** detailed full-color pixel art (Stardew Valley / Hollow Knight register) — no fixed or limited palette. The world art is rich and art-directed; the UI is consciously LO-FI — flat colors, integer-pixel borders, no anti-aliasing, no glow, no glassmorphism.

**UI theme palette (existing in code — `COLORS` in `src/config/constants.ts`):**
- `#0a0a1a` — void / world background (deep cosmic blue-black)
- `#081820` — primary text on light surfaces (darkest)
- `#346856` — secondary text / borders
- `#88c070` — accent / highlight
- `#e0f8d0` — UI panel fill / button text (lightest)
- `#06b6d4` — interactive cyan (selection / focus rings)

These are **UI chrome tokens only** — region backdrops, characters, and props are full-color and not limited to this set.

**Typography:** Press Start 2P (loaded). Pixel-perfect at multiples of 8. Sizes already standardized at 8 / 12 / 16 / 24 / 40.

**Anti-references:** modern flat-with-shadows admin UI, neon-on-black AI dashboards, gradient-text marketing pages, Material Design rounded cards. Don't apply web-first typography rules (clamp, OKLCH, container queries) — they don't render in a Phaser canvas anyway.

**Theme:** Dark world (gameplay), light UI panels (text). Dialogue boxes are bright cream so text is comfortable to read against the dark void.

### Design Principles
1. **Readable before remarkable.** This is a text-heavy narrative game. Alignment, baseline grid, and contrast win over decoration.
2. **8-pixel grid, always.** Every X/Y position, padding, font-size, and border thickness is a multiple of 4 (preferably 8). No arbitrary 13s, no 18s.
3. **Borders are integer pixels, not stretched art.** Don't scale 256×256 frames 5× — render UI chrome from primitive shapes (Graphics rectangles + 1–2px strokes) so corners and borders stay crisp.
4. **One panel style across all UI.** Dialogue, HUD card, settings modal, puzzle frames, and interactive Choice Buttons all share the same visual language: cream fill, dark frame, double-stroke if needed for emphasis. Stop mixing sprite-stretched panels with `Graphics.fillRect`.
5. **Hierarchy through weight, not color.** Speaker name vs. body, title vs. subtitle — drive these with size and the existing palette, not new accent colors.

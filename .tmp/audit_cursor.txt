## Rendering “glue” is strong by design

The game explicitly commits to pixel rendering and integer rounding, which acts as a unifying lens over mixed asset sources:

```171:178:D:/algo/src/config/gameConfig.ts
  pixelArt: true,
  antialias: false,
  roundPixels: true,

  render: {
    pixelArt: true,
    antialias: false,
  },
```

`CRTScene` then stacks **scanlines**, **vignette**, and a faint **Game Boy cream** phosphor sweep (`0xe0f8d0`) on top of everything:

```74:83:D:/algo/src/scenes/CRTScene.ts
    // Electron-gun sweep: faint GB-green glow line traveling downward
    this.refreshY += delta * 0.11;
    if (this.refreshY > height + 12) this.refreshY = -12;

    const ry = Math.floor(this.refreshY);
    this.refreshLine.clear();
    this.refreshLine.fillStyle(0xe0f8d0, 0.015);
    this.refreshLine.fillRect(0, ry, width, 2);
    this.refreshLine.fillStyle(0xe0f8d0, 0.007);
    this.refreshLine.fillRect(0, ry + 2, width, 4);
```

**Cohesion takeaway:** mechanically, nothing is presented as crisp “modern flat UI”; the stack pushes everything toward retro display hardware. That is a coherent *product* choice even when individual sprites were made at different times.

Design rules in `CLAUDE.md` center a **four-color GB family** plus **cosmic accents**, with cyan reserved for interactivity. The canonical tokens live in `COLORS`:

```12:43:D:/algo/src/config/constants.ts

  VOID_BLACK: 0x0a0a1a,
  COSMIC_PURPLE: 0x1a1a3e,

  PURPLE_CRYSTAL: 0x8b5cf6,

  GOLD_ACCENT: 0xfbbf24,

  ERROR: 0x081820,   // Highest contrast dark
  WARNING: 0x346856, // Medium dark
  // ...
  OVERLAY_BG: 0x0a0a1a, // Void backdrop
  // Concept Bridge / shared nav chrome
  NAV_DOT_INACTIVE: 0x3a3a5a,
  BRIDGE_PATTERN: 0x22c55e,
  BRIDGE_WRONG: 0xef4444,
```

**Cohesion tension:** `RegionBackdrop`’s procedural prologue lattice uses **`0x22d3ee`** (a bright cyan/teal stroke) at low alpha:

```93:96:D:/algo/src/ui/RegionBackdrop.ts
    // Hex grid — diagonal subtle lattice.
    const grid = this.scene.add.graphics().setDepth(DEPTH_SKY + 1).setScrollFactor(0).setAlpha(0.08);
    grid.lineStyle(1, 0x22d3ee, 0.6);
```

That sits in the same *hue family* as `CYAN_GLOW` (`#06b6d4`) but is **not** wired through `COLORS`. Visually it is probably fine at 8% opacity, but conceptually it blurs “cyan = interaction” unless players never confuse ambient grid with clickable UI—worth a conscious pass.

Similarly, Concept Bridge greens/reds (`BRIDGE_*`) step outside strict GB-four; again defensible for pedagogy, but it is a **second accent system** alongside GB + cosmic prologue.

## Asset pipelines create predictable “waves” of style

`assets.ts` shows a deliberate **tiered universe**: `prologue`, `prologue_rework`, `prologue_sheets`, per-region folders, and a large **`visual_revamp`** manifest. Naming already encodes rollout (`_v2` on Array Plains / Twin Rivers grounded maps, `_v1` elsewhere):

```114:119:D:/algo/src/config/assets.ts

  { key: VISUAL_REVAMP_KEYS.PROLOGUE_BG, path: `${VISUAL_REVAMP_BASE}/regions/prologue_chamber.png` },
  { key: VISUAL_REVAMP_KEYS.ARRAY_PLAINS_BG, path: `${VISUAL_REVAMP_BASE}/regions/array_plains_grounded_v2.png` },
  { key: VISUAL_REVAMP_KEYS.TWIN_RIVERS_BG, path: `${VISUAL_REVAMP_BASE}/regions/twin_rivers_grounded_v2.png` },
  { key: VISUAL_REVAMP_KEYS.HASH_HIGHLANDS_BG, path: `${VISUAL_REVAMP_BASE}/regions/hash_highlands_grounded_v1.png` },
```

**Cohesion takeaway:** the *code* expects regional parity (`VISUAL_REVAMP_KEYS.*` for basically everything). The filenames tell you **production readiness is uneven**: some regions and puzzle backdrops will read as “new pass” vs “older pass” unless art direction is tightened globally. That is not a bug; it is a visibility of **multi-generation art DNA** sitting under one unified loader.

Boot flow also acknowledges **streaming cost**: minimal boot preload; heavier art is queued by owning scenes—which is smart for UX but means **first paint per region** can expose loading-order quirks (flash of fallback color, etc.), which can feel like cohesion breaks even when assets are fine.

## Puzzle screen composition is intentionally layered—and the comments matter

`BasePuzzleScene` documents the intended stack: void fill → **full-screen static illustration** (`setDisplaySize(width, height)`) → **`RegionBackdrop` as ambient-only** → chrome:

```118:152:D:/algo/src/scenes/puzzles/BasePuzzleScene.ts
    this.add.rectangle(0, 0, width, height, COLORS.OVERLAY_BG, 1).setOrigin(0, 0).setDepth(-30);

    // Always render the static backdrop as the BASE LAYER. A puzzle's
    // `getPuzzleBackdropKey()` should now return the pixel-art region BG
    // (ARRAY_PLAINS_BG / TWIN_RIVERS_BG / etc.) so the marketing-grade art
    // is what the player sees. RegionBackdrop is composed ON TOP as a thin
    // ambient-motion layer (drifting dust, sway) — the heavy procedural
    // cartoon scenery (windmill, barn, hills, sky gradient) it used to
    // render has been stripped ...
    const backdropKey = this.getPuzzleBackdropKey();
    // ...
      this.add
        .image(width / 2, height / 2, resolvedBackdropKey)
        .setDisplaySize(width, height)
        .setDepth(-29);
```

**Cohesion strengths**

- Illustration-forward puzzles match overworld mood (same keys family as regions).
- `NAME_IT_PORTRAIT_MAP` ties speaker strings to **`VISUAL_REVAMP_KEYS`** portraits—clean narrative/UI bridge.

**Cohesion risks**

1. **Non-native aspect ratios** stretched to fixed 1280×720 (`gameConfig`): if source art ratios differ region by region, you get subtly different vertical composition or softness perception under `Scale.FIT` on user monitors.
2. **Frame geometry**: default frame uses rounded rects and shadows (`createPuzzleFrame`), while broader UI guidance favors **knife-sharp panels** via `drawPanel`. That is two “chrome dialects”: soft rounded viewport vs sharp HUD strips (e.g. controls strip uses `drawPanel`).

Themes in `puzzleTheme.ts` are the right abstraction to align frame chrome with region identity; cohesion depends on how consistently subclasses override `getPuzzleTheme()` vs staying on parchment default everywhere.

## Summary verdict

| Layer | Cohesion role |
|--------|----------------|
| Renderer + CRT | Strong global filter; hides minor asset inconsistencies |
| `COLORS` / themes | Strong *when used*; watch stray hex outside tokens |
| `visual_revamp` manifest | Single pipeline, but filenames expose generational drift |
| Layering model | Clear and modern; minimizes procedural vs painted conflict |

**Highest-impact cohesion levers visible from code:** finish the `_v2`-style pass across all regions/backdrops referenced in `VISUAL_REVAMP_IMAGE_ASSETS`, align decorative cyan with `COLORS.CYAN_GLOW` policy, and reconcile **rounded puzzle frame** vs **sharp panel** language so HUD and puzzle chrome feel like one system.
